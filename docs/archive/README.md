# Archive

Working documents from before the harness existed, moved here in phase B of the
harness restructure (see
[`../2026-08-10-harness-restructure.md`](../2026-08-10-harness-restructure.md)).

| Folder | What it holds |
|---|---|
| `plans/` | Implementation plans, 2026-06 to 2026-08 |
| `specs/` | Specifications predating `specs/` at the repo root |
| `audits/` | One-off audits |

**These are not current process documentation.** They were written under a
different working model and their conventions are superseded by `harness/`. Do
not follow a process described in here; follow [`../../CLAUDE.md`](../../CLAUDE.md)
and the rule files it routes to.

**They are kept because they are primary source material for phase C.** The
plans are the only record of *why* Canvas, Voice, the light mode and the chart
family are built the way they are. A spec reverse-engineered from code alone
describes the code including its mistakes; these documents are where the intent
behind a decision can still be recovered. Reach for them when a spec raises the
question "was that deliberate?".

Nothing in here is maintained. Where an archived document and the code disagree,
the code is what shipped.
