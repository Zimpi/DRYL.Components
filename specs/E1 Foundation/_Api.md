# Foundation — Public API

The public surface that belongs to no single component: theming types, the DI
registration, the AI state vocabulary, the motion primitives, and the token
surface consuming apps are allowed to override.

This category is componentless by design — see `SPEC-02` in
[`../../harness/requirements.md`](../../harness/requirements.md). It carries no
`F{n}` spec file, and no `Meta` block: it is a reference for the specs around
it, not a unit of implementation.
